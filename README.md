# 투신도시 GIRLS GIFT RPG (3DS) 한국어 패치

일본판 「闘神都市」(닌텐도 3DS, 타이틀 ID `0004000000112000`)의 비공식 한국어 패치입니다.

게임 데이터는 들어 있지 않고, 원본과의 차이(xdelta)만 들어 있습니다. 설치 프로그램이 가지고 계신 원본에서 한국어 파일을 만들어 모드 폴더(LayeredFS)에 넣습니다. 롬 파일 자체는 고치지 않습니다.

**받기:** [Releases](../../releases/latest)에서 `ToushinToshi3DS_Korean_Patch_v1.1.0.zip`

## 추가·변경 사항

원판(일본판 3DS 「闘神都市」, 타이틀 ID `0004000000112000`)과 비교해 이 패치가 바꾸거나 더한 것입니다. 괄호 안은 근거(릴리스 태그, 커밋, 파일 이름)입니다.

### 번역 범위

일본어 원본을 바탕으로 옮겼습니다. 음성은 일본어 그대로입니다.

- **대사·서술·선택지**: 본편 대사와 서술, 선택지를 모두 한국어로 옮겼습니다(v1.0).
- **화면 글자**: 메뉴, 아이템, 스킬, 전투, 상점, 카드, 걸즈 기프트 등의 화면 글자를 옮겼습니다(v1.0).
- **그림 글자**: 글자가 그려진 그림(단추, 제목, 설명 그림)을 한국어로 다시 그렸습니다. 타이틀 로고도 한글 「투신도시」로 바뀝니다(v1.0, README).
- **오프닝 영상**: 노래 가사와 제작진 자막을 한국어로 넣었습니다. 일본어 가사가 공개되지 않아, 한국어 가사는 노래에 맞춰 새로 지은 것입니다(v1.0).
- **실행 파일 속 글**: 장비 화면의 「해제」, 능력치 이름, 레벨업 문구 등 게임 실행 파일 안에 있던 일본어를 `code.ips`로 바꿨습니다(v1.0.1, 604f2ff, `installer/Installer.cs`).
  - 이름 입력 때 기호를 넣으면 뜨는 안내는 3DS 시스템 키보드 창이라, 한글 글꼴이 없는 기기를 생각해 영어로 넣었습니다(v1.0.1).
- **줄였던 대사 되살리기**: 이 게임은 대사마다 원문 길이만큼의 자리에 맞춰 넣어야 해서, v1.0.1까지는 많은 줄을 짧게 줄여 옮겼습니다. v1.1.0에서 한글을 더 적은 자리로 넣는 방법을 써서 여유를 만들고, 빠졌던 뜻·말끝·조사를 원문과 대조해 1,505문장을 되살렸습니다(v1.1.0, 61d6eb1).
  - 예: 「원래 그런 곳.」 → 「원래 그런 곳이야.」, 선택지 「도적 전투」 → 「도적과 싸운다」
- **미번역으로 남은 곳**: 이벤트 중에 나오는 메뉴 화면 사진 4장은 아직 일본어입니다(v1.0.1·v1.1.0 릴리스 노트).

### 추가된 기능

- **주인공 이름 한글 입력**: 완성형 한글 2,350자로 주인공 이름을 지을 수 있습니다(v1.0.1). 3DS 실기에서는 한글 자판이 있는 시스템 키보드가 있어야 칠 수 있습니다.
- **이름 뒤 조사 처리**: 받침 있는 이름(예: 「민준」)을 지어도 「민준는」「민준를」처럼 틀리지 않도록, 이름이 들어가는 408문장을 받침과 상관없이 자연스럽게 읽히는 문장으로 고쳤습니다(v1.1.0).
  - 예: 「나, 민준 너를 정말 좋아해.」, 「<이름>하고 더 이야기하고 싶지만」

### 화면 개선

- **선택지·가운데 정렬 글**: 「예 / 아니요」 같은 선택지와 가운데에 놓이는 글이 한글로 바꾼 뒤 왼쪽으로 치우쳐 보이던 것을 고쳤습니다(v1.0.1).

### 버그 수정

- v1.0에 번역이 빠져 남아 있던 일본어 몇 줄(「おかえれ」 등)을 옮겼습니다(v1.0.1).
- v1.0에서 선택지 정렬이 어긋나던 것을 고쳤습니다(v1.0.1).
- 설치 프로그램: `%APPDATA%\Azahar`가 다른 드라이브로 가는 정션(또는 심볼릭 링크)이면 폴더 이름 바꾸기가 「경로를 찾을 수 없음」으로 실패하던 것을, 실제 경로로 풀어서 처리하도록 고쳤습니다(v1.0.1, 604f2ff, `Installer.cs`의 `Resolve`).

### 설치·제거 방식

- **차분만 배포**: 게임 데이터는 들어 있지 않고, 원본과의 차이(xdelta3로 만든 `.xdelta` 245개)와 실행 코드 패치 `code.ips`만 들어 있습니다. 롬 파일 자체는 고치지 않고 모드 폴더(LayeredFS)에 결과를 넣습니다.
- **원본 읽기**: 복호화된 `.3ds`/`.cci`/`.cxi`/`.cia` 롬에서 romfs를 직접 찾아 읽거나(NCCH·IVFC 머리 확인), Azahar의 「Dump RomFS」 등으로 뽑은 romfs 폴더를 씁니다. 암호화된 롬이면 알려 주고 멈춥니다(`Installer.cs`).
- **원본 확인(해시)**: `manifest.tsv`에 파일마다 원본과 결과의 SHA-256·크기가 적혀 있어 설치할 때 비교합니다. 다만 원본이 달라도 설치를 막지 않고 기록 창에 경고만 남깁니다(xdelta3를 `-n -a`로 실행). 결과가 기대와 다른 파일 수도 기록합니다.
- **gzip 파일 처리**: `manifest.tsv`의 gzip 열이 1인 파일은 원본을 풀어 적용한 뒤 다시 묶고, 묶은 결과를 다시 풀어 같은지 확인합니다.
- **설치할 곳 세 가지**: Azahar(사용자 폴더 자동 찾기, 포터블판은 직접 고르기) → `load\mods\0004000000112000\` / 3DS SD 카드(Luma) → `luma\titles\0004000000112000\` / 고른 폴더로 내보내기.
- **`code.ips` 두 자리**: Azahar용 `exefs\code.ips`와 Luma용 `code.ips` 두 곳에 함께 넣습니다. IPS라 두 번 적용돼도 결과가 같습니다(v1.0.1, 604f2ff).
- **임시 폴더에 먼저 만들기**: 결과를 `...0004000000112000.installing`에 다 만든 뒤 바꿔 넣으므로, 도중에 실패해도 쓰던 폴더가 망가지지 않습니다.
- **백업**: 이미 투신도시 모드 폴더가 있으면 지우지 않고 `0004000000112000.backup-날짜-시각`으로 이름을 바꿔 둡니다.
- **설치 기록 파일**: 설치한 폴더에 `tt3_korean_patch.txt`(판 번호, 설치 시각, 적용한 파일 수, 경고 수)를 남깁니다.
- **제거**: 같은 「설치할 곳」에서 **제거**를 누르면, 위 기록 파일이 있는 폴더만 휴지통으로 옮기고 가장 최근 백업을 되돌립니다. 이 설치 프로그램이 넣지 않은 폴더는 지우지 않습니다.
- **명령 줄(시험용)**: `--source <롬|폴더> --target-dir <...\0004000000112000> [--log <파일>]`, `--uninstall --target-dir <...> [--log <파일>]`.
- **지원 환경**: Azahar 에뮬레이터, 3DS 실기(Luma3DS, 「Enable game patching」 켜야 함). 저장 데이터는 판을 올려도 그대로 이어서 쓸 수 있습니다(v1.1.0).

### 알려진 문제

- 이벤트 중에 나오는 메뉴 화면 사진 4장은 아직 일본어입니다.
- 원본 파일이 패치가 기대한 것과 다르면 그 파일은 제대로 바뀌지 않았을 수 있습니다(설치는 막지 않고 경고만 남김).
- 3DS 실기에서 한글 이름을 치려면 한글 자판이 있는 시스템 키보드가 필요합니다. 실기에서의 확인은 릴리스 노트에 적혀 있지 않습니다(Azahar에서만 확인한 것으로 추정) (추정).
- 다른 투신도시 모드나 패치와 함께 쓰는 것은 지원하지 않습니다.

## 준비물: 원본 (둘 중 하나)

- 복호화된 롬 파일: `.3ds` / `.cci` / `.cxi` / 복호화된 `.cia`
- romfs 폴더: Azahar 게임 목록에서 투신도시를 오른쪽 클릭 → **Dump RomFS** 로 뽑은 폴더 등

암호화된 롬은 읽을 수 없습니다. 자기 3DS에서 복호화해 뽑은 롬을 쓰세요. Azahar도 암호화된 롬은 켜지 않습니다(암호화된 CIA는 설치 단계에서 거부됩니다). 이것은 패치와 상관없는 Azahar 정책입니다.

## 설치

1. 압축을 모두 풉니다(설치 프로그램 옆의 `patch`·`tools` 폴더가 있어야 합니다).
2. `투신도시3DS_한국어패치_설치.exe`를 실행합니다. 서명 없는 프로그램이라 「Windows의 PC 보호」 창이 뜨면 **추가 정보 → 실행**을 누르세요.
3. **1. 원본**에서 롬 파일이나 romfs 폴더를 고릅니다.
4. **2. 설치할 곳**을 고르고 **설치**를 누릅니다.
   - **Azahar**: 사용자 폴더(보통 `%APPDATA%\Azahar`)를 저절로 찾습니다. 포터블판은 「직접 고르기」로 `azahar.exe`가 있는 폴더를 고르세요. 결과: `...\load\mods\0004000000112000\romfs\` 와 `exefs\code.ips`
   - **3DS SD 카드**: 결과는 `SD:\luma\titles\0004000000112000\romfs\` 와 `code.ips`. 넣은 뒤 SELECT를 누른 채 3DS를 켜서 Luma 설정의 **Enable game patching**을 켜고 저장하세요.
   - **폴더로 내보내기**: 고른 폴더에 `0004000000112000\romfs`를 만듭니다.
5. 이미 투신도시 모드 폴더가 있으면 지우지 않고 `0004000000112000.backup-날짜`로 이름을 바꿔 둡니다.
6. 게임을 켜서 타이틀 로고가 한글 「투신도시」로 나오면 적용된 것입니다.

**지우기:** 설치 프로그램에서 같은 「설치할 곳」을 고르고 **제거**를 누르면 패치 폴더를 휴지통으로 옮기고, 백업이 있으면 되돌립니다.

## 알아 둘 점

- 3DS 실기에서 이름을 한글로 치려면 한글 자판이 있는 시스템 키보드가 있어야 합니다.
- 오프닝 노래는 일본어 가사가 공개되지 않아, 한국어 가사 자막은 노래에 맞춰 새로 지어 넣었습니다.
- 원본 파일이 패치가 기대한 것과 달라도 설치는 막지 않고 기록 창에 경고만 남깁니다. 이 경우 그 파일은 제대로 바뀌지 않았을 수 있습니다.
- 다른 투신도시 모드나 패치와 함께 쓰지 마세요.

## 설치 프로그램 없이 직접 적용하려면

`patch` 폴더의 `.xdelta`는 xdelta3로 만든 파일 245개입니다(romfs 안 경로 + `.xdelta`). `manifest.tsv`의 gzip 열이 1인 파일은 원본을 gzip으로 풀고 적용한 뒤 다시 gzip으로 묶어야 합니다.

```
xdelta3 -d -s 원본(푼 것) patch\sys_scene.bin.xdelta 결과
```

`patch\code.ips`는 원본 없이 그대로 씁니다. Azahar는 `0004000000112000\exefs\code.ips`, Luma는 `0004000000112000\code.ips`에 둡니다.

## 소스

설치 프로그램 소스는 [`installer/Installer.cs`](installer/Installer.cs)입니다. 윈도에 기본으로 있는 .NET Framework 4의 `csc.exe`로 빌드합니다.

```
csc /target:winexe /codepage:65001 /r:System.Windows.Forms.dll /r:System.Drawing.dll /r:Microsoft.VisualBasic.dll Installer.cs
```

함께 배포하는 `xdelta3.exe`는 [xdelta3 3.2.0](https://github.com/jmacd/xdelta)(Apache License 2.0)입니다.
